# GCP Simple Python App 🚀✨

A simple Python app using [waitress](https://docs.pylonsproject.org/projects/waitress/en/latest/) and [flask](https://flask.palletsprojects.com/).

Uses the Google Cloud metadata service. It also features a fun bouncing image 🤸‍♂️ and some celebratory emojis! 🎉

Run locally with:
```
cd app
python3 -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt
python3 app.py
```
